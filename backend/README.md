# Whisky Index — Backend (NestJS)

API на NestJS (TypeScript). Отдаёт цены продуктов из Postgres и данные об акциях
(через сторонний API котировок).

## Запуск

```bash
cp .env.example .env
npm install
npm run start:dev
```

API поднимется на `http://localhost:3000/api`.

## Эндпоинты (скелет)

| Метод | Путь            | Описание                                  |
| ----- | --------------- | ----------------------------------------- |
| GET   | `/api/health`   | Проверка живости                          |
| GET   | `/api/products` | Стандартный список продуктов              |
| GET   | `/api/stocks`   | Стандартный набор акций (2007)            |
